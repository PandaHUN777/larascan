# Security Policy

## Supported Versions

Only the latest major and minor versions receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover any security-related issues in **Larascan**, please do **NOT** open a public issue.

Instead, please report security vulnerabilities responsibly:

1. **Email:** Send details directly to **mrbalasare@gmail.com**.
2. **GitHub Security Advisory:** Submit a private advisory at [https://github.com/emrebalasar/larascan/security/advisories/new](https://github.com/emrebalasar/larascan/security/advisories/new).

Please include:
- A description of the vulnerability.
- Steps to reproduce the issue or a minimal reproducible example (PoC).
- Any potential impact on users or systems.

We will acknowledge receipt of your report within 48 hours and work on a fix as quickly as possible.
